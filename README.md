# 👁️ Mubsir — AI Security System for Hajj

Mubsir is a computer vision prototype developed as part of the **Health & Security in Hajj Hackathon Forum**.

The project explores the use of computer vision to support security personnel in monitoring inspection points and critical locations during Hajj.

## 🎯 Project Goal

The project was designed to explore how AI-powered visual monitoring could support security operations and improve situational awareness in high-density environments.

## 💡 Prototype

The current prototype demonstrates:

- Face detection using OpenCV
- Camera-based image processing
- Normal camera visualization
- Thermal-style visualization
- Interactive interface built with Streamlit

## 🛠️ Technologies

- Python
- OpenCV
- Streamlit
- NumPy
- Computer Vision
- Image Processing
